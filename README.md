# GifOverlay

Windows용 애니메이션 오버레이입니다.

## 실행 방법

배포 ZIP의 압축을 모두 푼 뒤 `GifOverlay.exe`를 실행합니다. 소스로 실행할 때는 Java 21에서 `Run-GifOverlay.cmd`를 실행합니다.

## 사용 방법

1. 설정 창의 **애니메이션**에서 GIF나 `.overlay.zip`을 선택합니다. 파일을 설정 창에 끌어 놓아도 됩니다.
2. 소리를 함께 재생하려면 **WAV**에 파일을 넣고 **소리 재생**을 체크합니다.
3. **클릭 방지**를 풀고 이미지 본문을 드래그해 위치를 옮깁니다. 오른쪽 아래 파란 손잡이를 드래그하면 크기가 바뀝니다.
4. 조절을 마치고 **클릭 방지**를 켜면 오버레이 위의 클릭이 뒤쪽 창으로 전달됩니다.
5. 트레이 아이콘이 등록된 상태에서는 **X** 또는 **트레이로 최소화**로 설정 창을 숨겨도 이미지와 소리가 계속 재생됩니다. 트레이의 **설정**으로 창을 다시 열고, **완전 종료**로 앱과 재생을 끝냅니다.

기능이 헷갈리면 버튼이나 항목 이름에 마우스를 올려 도움말을 확인하세요.

## 주요 기능

- **여러 오버레이** — `+`로 탭을 추가해 동시에 재생합니다. 탭 이름은 더블클릭해 바꾸고, 추가 탭은 `−`로 닫습니다. 열어 둔 탭과 설정은 다음 실행 때 복원됩니다.
- **보관함** — **현재 조합 저장**으로 애니메이션, WAV와 설정을 저장합니다. 미리보기의 **♪**는 WAV 연결 표시입니다. 원본 파일을 옮겼다면 **경로 변경**에서 다시 지정합니다.

## 오버레이 ZIP 직접 만들기

1. 가로·세로 크기가 같은 PNG를 준비합니다. 투명 배경이 필요하면 투명도를 유지해 저장합니다.
2. `frames` 폴더에 재생 순서대로 `0.png`, `1.png`, `2.png`처럼 번호를 빠짐없이 붙여 넣습니다.
3. `frames` 폴더를 ZIP으로 압축하고 파일 이름을 `내_애니메이션.overlay.zip`처럼 지정합니다. ZIP을 열면 `frames` 폴더가 바로 보여야 합니다.
4. GifOverlay의 **애니메이션**에서 ZIP을 엽니다. 기본 간격은 프레임당 **100ms**입니다. **ZIP 프레임 간격 고정**을 켜고 값을 바꾸면 재생 속도를 조절할 수 있습니다.

```text
내_애니메이션.overlay.zip
└── frames/
    ├── 0.png
    ├── 1.png
    └── 2.png
```

### 추가 기능 — 프레임별 표시 시간 설정

프레임마다 표시 시간을 다르게 하려면 ZIP 안에서 `frames` 폴더와 같은 위치에 `delays.txt`를 넣습니다. `0.png`부터 순서대로 프레임마다 밀리초 단위 숫자를 한 줄에 하나씩 적고, 앱의 **ZIP 프레임 간격 고정**을 끕니다.

```text
100
100
300
```

이 예에서는 처음 두 프레임이 각각 0.1초, 세 번째 프레임이 0.3초 동안 표시됩니다.

버전별 기능과 변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 기록한다. 작업 절차는 [AGENTS.md](AGENTS.md)를 참고한다.
